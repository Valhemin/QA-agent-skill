# CLAUDE.md — <PROJECT_NAME>

Automated test repo (Playwright + TypeScript) for a frontend web application.

## How to work: AI-first

The user is a **QA, not a developer**. They speak in plain language, not in commands.

**Every QA-related request goes through the `qa` skill** (`.claude/skills/qa/SKILL.md`).
That skill detects what needs to be done and runs the right workflow. Don't make the user
pick a skill or type commands.

Examples of requests the agent must handle end-to-end:
- "run the login tests and see what happens"
- "write a test for the shopping cart" + a requirements description
- "here are the test cases I came up with, what's missing"
- "dev just finished the payment screen, compare it against Figma: <link>"
- "the price bug from earlier — write a bug ticket for dev"
- "any issues before we release"

### Autonomous behaviour

Check the repo before asking: mapping table in `data/feature-map.md`, `data/he-thong.json`,
`requirements/`, `testcases/`, `reports/ai/summary.json`, example code in `pages/auth/`.

**Only ask when the answer determines the outcome and can't be found in the repo.** Batch
multiple questions into one message.

### Deliver results, not steps

The user wants **results**, not progress updates. Do the full job:
write code → run `tsc` + `lint` → run real tests → concise report with next steps.

Don't say "done" before verifying. Don't ask mid-task about things that can be looked up.

## Rule #1: never guess

- Uncertain → **stop and ask**. Don't infer and keep going.
- No data → say "no data yet". Don't invent locators or test results.
- Unclear point → **skip it, add it to "Needs clarification"** at the end of the report, continue with everything else.
- Only assert what has been verified with a real command or file.

## Source of truth

`.claude/rules/testing-conventions.md` — core rules (no-guess, memory) + index pointing to
`writing-tests.md` / `edge-cases.md` / `running-tests.md` / `figma.md`. Each sub-skill reads
only the file it needs; avoid loading everything on every turn.

## Before marking complete

```bash
npx tsc --noEmit         # must be clean
npm run lint             # must be clean — blocks raw locators in specs
npm run check:reporter   # self-check for error classification + FE/BE assignment
```

New tests must **pass green for real at least once**.

## Official Playwright agents

`playwright-test-planner` / `generator` / `healer` (generated by `npx playwright init-agents`).
Use them when you need to explore the real app to get real locators.

**Healer is high risk**: it can weaken assertions to make a broken test go green, hiding real
bugs. Never let it auto-merge — see rule file section 6.

## IDE sync

After editing `.claude/` → run `npm run sync:ide`. CI blocks if you forget.
